# VECTOR-7 — сайт-портфолио

Статический сайт на чистом HTML + CSS + JS. Без сборки, без npm. Весь контент — в JSON-файлах в `content/`.
Деплой на GitHub Pages через GitHub Actions при каждом пуше в `main`.

```
site/
├── index.html              каркас страницы (не трогать без нужды)
├── css/style.css           все стили; токены (цвета/шрифты) — в :root сверху
├── js/app.js               загрузка JSON, рендер секций, навигация, лайтбокс
├── js/blocks.js            рендереры кастомных блоков (text / images / cards / cta / html)
├── content/
│   ├── site.json           позывной, меню, порядок секций, hero, футер, статус заказов
│   ├── gallery.json        работы, фильтры, раскладка сетки
│   ├── commissions.json    тарифы, процесс, условия
│   ├── operations.json     цели, прогресс, таймлайн
│   ├── support.json        способы поддержки
│   └── blocks.json         ваши кастомные блоки
├── assets/img/             картинки работ
├── assets/fonts/           Eurostile (лицензионные, не публикуйте репо как public без проверки лицензии)
├── .github/workflows/deploy.yml
├── README.md               этот файл
└── AI_GUIDE.md             инструкция для AI-ассистентов (стиль, схемы JSON, правила)
```

## Локальный запуск

JSON грузится через `fetch`, поэтому открыть `index.html` двойным кликом (file://) не получится. Нужен любой локальный сервер:

```bash
# Python
python -m http.server 8080
# или Node
npx serve .
```

Открыть http://localhost:8080. После правки JSON — просто обновить страницу (кэш обходится автоматически).

## Деплой на GitHub Pages

1. Создайте репозиторий, залейте содержимое папки `site/` в корень репо, ветка `main`.
2. Settings → Pages → Source: **GitHub Actions**.
3. Любой пуш в `main` запускает `deploy.yml`: сначала проверка, что все JSON валидны, затем публикация.
4. Сайт появится на `https://<user>.github.io/<repo>/`.

Все пути в проекте относительные, поэтому он работает и в подпапке репозитория, и на своём домене (добавьте файл `CNAME`).

## Как редактировать

### Тексты и языки
Любое поле, которое должно переводиться, записывается объектом `{ "EN": "...", "RU": "..." }`. Обычная строка — одинакова для обоих языков. Переключатель EN/RU в шапке запоминает выбор в браузере. Язык по умолчанию: `site.json → defaultLang`.

### Статус заказов (пилюля в шапке)
`site.json → commissionStatus`: `"open"` | `"waitlist"` | `"closed"`.

### Добавить работу в галерею
1. Положите файл в `assets/img/` (JPG/WebP, до ~2500px по длинной стороне, до 600 KB).
2. Добавьте объект в `gallery.json → items`:
```json
{ "id": "w09", "src": "assets/img/my-work.jpg", "label": "MY_WORK", "tag": "TFR",
  "series": "The Fire Rises / Posters", "year": "2026", "medium": "DIGITAL",
  "dims": "3000×4000", "tools": "CLIP STUDIO", "cjk": "烈火", "col": "1 / 5", "row": "6 / 8" }
```
- `tag` должен совпадать с одним из `filters`.
- `col` / `row` — положение в 12-колоночной сетке (ряд = 150px). Уберите их, чтобы плитка встала автоматически. На планшете/мобильном сетка сама схлопывается.
- `src: ""` — покажется серая рамка-плейсхолдер с надписью `label`.

### Тарифы, цели, донаты
Правьте соответствующие JSON. `slots: 0` в тарифе автоматически показывает `QUEUE FULL`. Первая операция в `operations.json` дублируется как приоритетная цель в разделе SUPPORT. В `support.json → methods`: строка с `url` даёт кнопку OPEN, строка с `copy` — кнопку COPY (копирует в буфер).

### Порядок секций и кастомные блоки
`site.json → sections` задаёт порядок. Стандартные типы: `hero`, `gallery`, `commissions`, `operations`, `support`. Кастомный блок подключается так:
```json
{ "type": "block", "id": "prints" }
```
где `prints` — `id` блока из `blocks.json`. Типы блоков и их поля — в `AI_GUIDE.md`. Чтобы блок появился в меню, добавьте его в `site.json → nav` с тем же `id`.

Новый тип блока: добавьте функцию в `js/blocks.js` и стили `.blk-<type>` в `css/style.css`.

### Цвета и шрифты
Всё в `css/style.css → :root`. Меняйте там, а не по месту.

## Правила стиля (коротко)
Чёрный #000 фон, 1px линии #2F3336, акценты редко: фиолетовый #7B5CFF (UI), циан #5EEAD4 (статусы), золото #C9A227 (только деньги/донат), кармин #B42318 (нет мест). Eurostile Extended Bold — заголовки, Eurostile Medium — навигация и кнопки, IBM Plex Sans — текст, IBM Plex Mono — метаданные, Noto Serif TC — иероглифические акценты. Полная версия в `AI_GUIDE.md`.

## Что не забыть перед публикацией
- Заменить `#` в ссылках (футер, донаты, REQUEST, FOLLOW UPDATE) на реальные URL.
- Вписать настоящие крипто-адреса в `support.json`.
- Проверить лицензию на шрифты Eurostile для веб-использования.
